# Manuel court — espace organisateurs

## Se connecter

1. Ouvrez l’adresse du site suivie de `/admin`.
2. Saisissez le courriel et le mot de passe de votre compte organisateur.
3. Pour fermer votre session, cliquez sur **Se déconnecter**.

## Suivre les réservations

Dans **Vue d’ensemble**, consultez les paiements à vérifier, le remplissage, les totaux et les réservations récentes.

Dans **Réservations** :

- cherchez par nom, courriel ou code;
- filtrez par statut : à vérifier, en attente, confirmée ou annulée;
- ouvrez une réservation pour consulter sa fiche;
- cliquez sur **Exporter les confirmés (CSV)** pour télécharger la liste des personnes confirmées.

## Décider d’un paiement

Sur une réservation **À vérifier**, comparez le montant, le nom de l’expéditeur et le code avec le virement reçu dans le compte bancaire.

- Si le virement correspond, cliquez sur **Confirmer le paiement**. Un courriel de confirmation est envoyé.
- Si le paiement ne correspond pas, choisissez un **Motif du refus**, puis cliquez sur **Refuser le paiement**. La personne conserve ses places et peut envoyer une nouvelle preuve.
- Les réservations en attente restent actives jusqu’à une décision manuelle. L’annulation libère les places. Utilisez-la seulement si la réservation doit être annulée.

**Limite actuelle :** la fiche indique qu’une preuve a été reçue, sa date et sa taille, mais n’affiche pas la capture. Vérifiez le virement dans le compte bancaire avant toute décision. Ne confirmez pas un paiement sur la seule base de la présence d’une preuve.

## Modifier l’événement

Dans **Paramètres**, modifiez la date et l’heure, la date limite de réservation, le lieu, le nombre de places, les prix et l’adresse Interac. Cliquez sur **Enregistrer les modifications**; le site public est mis à jour aussitôt.

Le nombre de places ne peut pas être inférieur aux places déjà prises. Un changement d’adresse Interac demande de confirmer que le dépôt automatique est activé. Les réservations existantes gardent leurs conditions de paiement.

## Exporter les personnes confirmées

Le fichier CSV contient les coordonnées et les renseignements nécessaires à l’accueil. Gardez-le dans un emplacement privé et partagez-le uniquement avec les personnes qui en ont besoin pour l’organisation.
